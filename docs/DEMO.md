# Демо интерфейса FIINOPS

Отдельная статическая демонстрация для проверки экранов в браузере без сервера
приложения, PostgreSQL, Telegram и внешних API. Использует те же HTML/CSS/JS,
что рабочая панель; добавочный `demo/demo.js` имитирует ответы API только в браузере.
Рабочий сервер этот файл не загружает, его вход и права не меняются.

В верхней полосе можно выбрать кабинет руководителя или владельца и сбросить
демо. Все имена, проекты, документы и деньги вымышлены. Изменения хранятся в памяти
страницы до обновления; только выбранная роль сохраняется в sessionStorage.
Отчётные периоды и действия демонстрируют интерфейс, а не серверный финансовый
учёт. Выгрузка в демо — CSV; рабочая версия сохраняет полноценный XLSX.
Подтверждение получения через Telegram, OCR и реальная авторизация здесь отсутствуют.

## Локальный запуск

```bash
python scripts/build_demo.py --output demo-build
python -m http.server 8088 --directory demo-build
```

Открыть `http://localhost:8088/` в браузере на этом же компьютере.
В Windows вместо `python` можно использовать `py`.

## Публикация

Каталог сборки публикуется отдельно в корне ветки `gh-pages` через GitHub Pages.
В публикацию входят только `index.html`, `app.js`, `app.css`, `demo.js`, `demo.css`
и `.nojekyll`. Файлы настроек, база, архивы и серверный код не публикуются.

Включение сайта: GitHub → репозиторий → Settings → Pages → Source:
Deploy from a branch → Branch: `gh-pages`, каталог `/ (root)` → Save.
Для текущего репозитория настройки:
https://github.com/akizyakov-arch/zatratpro/settings/pages

После завершения публикации GitHub покажет адрес:
https://akizyakov-arch.github.io/zatratpro/
