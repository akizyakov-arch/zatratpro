# Голосовые отчёты: первый прототип

В личном чате руководителя доступны кнопка «ИИ-отчёты», голосовые сообщения и
команда `/ask ВОПРОС`. Системный владелец и сотрудник не получают финансовые
права руководителя. Проверки компании выполняются до обращения к внешним API
и заново при чтении отчёта.

Два первых сценария:

- «Сколько денег выдано по проекту Офис Север за всё время?»
- «Сколько денег выдано Иванову по проектам за октябрь 2026 года?»

Название должно однозначно определять сотрудника или проект своей компании.
Если совпадений несколько, бот предлагает уточнить вопрос; продолжение диалога
с сохранением параметров пока не реализовано. Для текстовых вопросов используется
явная команда `/ask`, чтобы не перехватывать создание проектов и другие действия.

Голос: максимум 120 секунд и 10 МБ. AssemblyAI Universal-2 получает аудио и
распознаёт русский (`language_code=ru`). Нужен `ASSEMBLYAI_API_KEY`; облачный
секрет `ASSAMBLY` также принимается. Аудио скачивается в ограниченный буфер
памяти, на диск не сохраняется. После завершения или ошибки отправляется запрос
удаления транскрипции AssemblyAI; срок хранения исходного загруженного аудио
определяется политикой провайдера. Ошибка удаления отмечается в журнале.
Обработка ограничена по времени, задержки опроса асинхронные.

DeepSeek получает только текст вопроса и короткое описание разрешённого отчёта.
Он возвращает строго проверяемые параметры, не SQL. Названия разрешаются локально
в компании пользователя. База агрегирует суммы в одном снимке; ответ формируется
шаблоном без повторного запроса модели. Содержимое документов и операции в ИИ
не передаются. Лимит — 5 запросов в минуту на пользователя.

Считается сумма оформленных выдач по дате создания. Период — UTC, конечная дата
включительна. По умолчанию текущий месяц, в ответе всегда указан фактически
понятый период. Отменённые выдачи исключаются по текущему статусу; неподтверждённое
получение тоже показывается по текущему статусу. Это не исторический остаток и
не сумма принятых расходов. Данные в RUB, группировка по проектам.

Для тестовых проектов и сотрудников выдачи отдельно не создавались, поэтому
нулевая сумма по ним ожидаема даже при наличии документов затрат.

Проверка подключения AssemblyAI выполнена на двухсекундном аудио без речи:
загрузка, обработка, получение пустой расшифровки и запрос удаления сработали.
Это проверка подключения, не проверка качества русской речи. Первую реальную
голосовую фразу нужно проверить в Telegram. Оба приведённых текстовых вопроса
проверены через настоящий DeepSeek и рабочую базу без изменения финансовых данных.
