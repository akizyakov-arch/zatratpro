## Статусы и приоритет документов

«Реализовано» означает наличие в коде указанного среза. Развёртывание и проверка
с реальными API — отдельные действия. «Частично» означает существующее ядро или
ограниченный интерфейс; это не обещание полного набора функций во всех каналах.
«План» — предложение развития, а не выполненная работа или утверждённый срок.

Актуальные общепродуктовые правила находятся в PRODUCT и TECHNICAL_SPECIFICATION.
Код и миграции — источник фактического поведения; расхождения документации с ними
нужно исправлять, а не считать документацию разрешением менять денежные правила.

[WEB_PANEL_REQUIREMENTS.md](WEB_PANEL_REQUIREMENTS.md) — исходное ТЗ панели версии
0.1 от 25.10.2026. Актуальные общие правила автоматического учёта новых расходов находятся
в PRODUCT и TECHNICAL_SPECIFICATION; исторические состояния отражаются отдельно. REVIEW_REFACTOR —
исторический анализ. Актуальные точки входа для продолжения работы перечислены
также в [PROJECT_STATE.md](../PROJECT_STATE.md).

Источники прежних постановок сохранены отдельно, без статуса действующего ТЗ:

[прежний PROJECT_STATE](archive/PROJECT_STATE_INITIAL.txt).
