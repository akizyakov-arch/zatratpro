# Вход в веб-панель через MAX

В браузере на странице входа доступны Telegram и MAX. Для MAX:

1. Нажать «Продолжить через MAX».
2. Скопировать показанную команду `/web_login КОД` и отправить её в личный чат
   со своим ботом FIINOPS в MAX.
3. Проверить браузер, пользователя и время, нажать «Подтвердить вход».
4. Вернуться в исходный браузер. Панель продолжит вход автоматически.

Переход по deep link MAX и MAX Mini App в этом изменении не реализованы;
ссылка/username бота MAX для входа не требуются. Кнопка Telegram сохраняет
прежний переход к Telegram-боту. После выбора другого способа действует последний
запрос в этом браузере.

## Права и границы

Работает для существующего активного руководителя компании и владельца системы.
MAX-only руководителю не требуется Telegram. Обычный сотрудник или неизвестный
аккаунт доступа не получает. Компания, права и история берутся из общего `users.id`;
вход не создаёт пользователя и не назначает роль.

`WebAuthService` — один общий механизм для обоих адаптеров. Браузер хранит
привязку в HttpOnly Secure cookie, срок запроса 5 минут. Коды и browser binding
в базе только в виде хешей. Канал выбран при создании: Telegram-код нельзя
подтвердить через MAX, даже если оба аккаунта связаны с одним пользователем.
После предъявления кода подтверждать может только предъявивший внешний аккаунт.
Права и наличие его привязки перепроверяются перед выдачей сессии. Сессия
выдаётся однократно только исходному браузеру; CSRF, отзыв и ограничения частоты
общие с Telegram. Команды и одноразовые коды не логируются.

## Обновление

Миграция 025 добавляет канал и нейтральный `external_id` в запросы браузерного
входа. Существующие Telegram-запросы получают `platform=telegram`, а их привязки
переносятся из `telegram_external_id`. Старое поле сохраняется для совместимости
данных; документы, финансовые записи и существующие веб-сессии не изменяются.

Перед миграцией сделать backup и остановить старые процессы Telegram, MAX и
панели. Затем запустить все три на одной версии: старый Telegram-обработчик
подтверждения не заполняет новое поле. Использовать те же Compose project,
.env и том PostgreSQL. HTTPS, домен и Caddy сохраняются. Сброс базы не нужен.

## Открытие из бота

В обоих ботах переход к панели находится в разделе «Отчёты» → «Панель
руководителя». В Telegram это прежнее Mini App; команда `/panel` сохранена.
В MAX бот отправляет нативную кнопку-ссылку «Открыть панель» для браузерного
входа. Этот переход не является MAX Mini App и не выдаёт сессию автоматически.
MAX использует `WEB_ORIGIN` независимо от включения Telegram Mini App.

Если вход не проходит, важен точный ответ бота: неизвестный MAX-аккаунт нужно
пригласить в компанию или связать с существующим профилем; сотрудник не получает
доступ руководителя. Для кода из браузера нужно выбирать именно MAX и завершать
вход в том же браузере в течение пяти минут. Код Telegram не подходит для MAX.
Скопированную команду нужно отправить в тот же MAX-бот, который использует БД панели.
